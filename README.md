# Mini proyecto frontend

## Descripción

Este proyecto corresponde al desarrollo de un prototipo web ligero orientado a la gestión de elementos interactivos en el navegador, considerando el contexto del usuario y sus preferencias personales. La propuesta se centra en ofrecer una experiencia completamente ejecutada del lado del cliente, construida con tecnologías web estándar y apoyada en capacidades nativas del navegador para representar información, permitir interacción directa y conservar datos entre sesiones.

Se espera una aplicación funcional, clara y autónoma, que demuestre criterio en la organización de la interfaz, en el comportamiento dinámico de sus componentes y en la definición de una lógica propia para resolver el problema planteado.
